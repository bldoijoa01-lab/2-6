## 전자칠판 추가 기능 (자습·자리바꾸기·말풍선 물리)
- **자습 시간 화면**: 사이드에 현재 시각(초 단위)·자습 종료까지 남은 시간·진행 막대·내일 챙길 것, 가운데에 안내 문구. 끝나는 시각은 일과 시간표의 지금 교시 끝(쉬는 시간이면 다음 수업 시작)에 맞춤. 자동 전환은 없고 수업 중 자습을 줄 때 선생님이 🖥 하단 버튼이나 리모컨으로 띄움.
- **자리 바꾸기**: 교실 배치(3분단, 교탁 아래)를 그대로 보여 주고 `🔀 자리 섞기`(전원 무작위), 두 자리 눌러 맞바꾸기, 처음 배치/번호순 복원. 배치는 전자칠판 기기에 저장. 기본 배치는 `public/kiosk.js`의 `SEAT_DEF`.
- **수업 의견 말풍선**: 아래에서 부력으로 떠올라 천장부터 쌓이고, 가득 차면 가장 오래된 것이 터짐. 말풍선을 잡아 끌어 던지면(드래그·플릭) 벽에 튕기다가 다시 떠오름.
- **청소 체크**: 전자칠판 청소 화면에서 이름을 누르면 ✓(완료 인원 표시), 서버(`cleanlog:<날짜>`)에 저장. 교사·관리자 화면의 "청소 기록"에서 최근 14일 완료/미체크 확인. 학생 계정은 접근 불가(`/api/clean`).
- **전자칠판 리모컨**: 관리자·교사 화면의 "🎛 전자칠판 리모컨"에서 화면 전환·타이머·자리 섞기·발표자 뽑기·모둠·공지 배너·청소 체크·딩동·새로고침을 원격 실행하고 전자칠판의 현재 상태를 확인. 전자칠판이 3초(밤엔 15초)마다 `/api/kiosk/poll`로 명령을 가져감(Durable Object, 학생 접근 불가).
- **자습 중 교실 이탈**: 전자칠판 자습 화면(＋등록: 이름 선택 + 사유 '밖에서 공부'/'기타'(+선택 메모), 돌아옴 버튼)과 리모컨에서 등록. `outlog:<날짜>` 저장, 교사·관리자 화면 "교실 이탈 기록"에서 최근 14일(사유·나간/돌아온 시각·소요 분) 확인. 학생 접근 불가(`/api/out`). 전자칠판의 타이머 기능은 제거.
- 말풍선은 부딪히면 찌부러졌다가 통통 튀고(스프링), 세게 던져도 사라지지 않음(화면 아래가 1.6초 넘게 막힐 때만 가장 오래된 것이 터짐).
- 말풍선은 천장부터 빽빽하게 차오르고, 서로 살짝 겹쳐 포개짐(새 것이 위). 화면 아래가 막히면 가장 오래된 것부터 터지며 정리.
- **받아쓰기(시험)**: 전자칠판 종례 화면의 🎙 버튼. 크롬 음성인식(ko-KR)으로 선생님 말씀을 실시간 글자로 보여 줌(끊기면 자동 재시작, 복사·지우기). 소리·글자 모두 저장하지 않고 화면을 나가면 사라짐. 정확도 확인용.
- **조회/종례 탭**: 전자칠판 하단 `📣 조회/종례` 하나로 조회(오전, 오늘 알림장+오늘 일과)와 종례(오후, 알림장+내일 챙길 것)를 상단 토글로 전환. 기본 조회 08:20~08:30(⚙에서 변경)이 되면 자동 전환, 리모컨에 🌅 조회 / 📣 종례 버튼. 안내사항은 두 화면 공용.
- **받아쓰기는 '오늘의 안내사항'에 통합**: 안내사항 카드의 🎙를 켜면 선생님 말씀이 줄 단위로 안내사항에 쌓이고 바로 저장·학생 반영(`↩ 마지막 줄 지우기`로 오타 줄 삭제). 한번 켜면 끄기 전까지 계속 듣고(다른 화면으로 가도 유지, 🔴 표시), 자꾸 끊기면 재시작 간격만 늘려 반복음을 줄임. 알림음(딩동/뽑기)은 볼륨을 낮춤.
- 안내사항은 줄마다 글머리(•)로 표시되고, 줄이 많으면 옆 칸으로 이어 붙여 한 화면에 보임(그래도 넘치면 글자 축소). 안드로이드 크롬이 같은 문장을 늘려 가며 반복 전송하는 받아쓰기 결과는 중복 제거. 조회 시작 전(평일 06시~)에는 헤더에 `🌅 조회까지 mm:ss` 카운트다운(1분 전 빨간 깜빡임).
- 조회/종례 화면에 `✅ 조회 끝`(종례면 `종례 끝`) 버튼(눌러 오늘 화면으로)과 안내사항 `🗑 전체 지우기`(3초 안에 한 번 더 눌러야 삭제) 추가.
- **받아쓰기 엔진**: 기본은 🧠 AI 인식(마이크를 말 끊김 기준 5~12초 조각으로 잘라 `/api/stt`→Workers AI Whisper, 무음 조각은 전송 안 함·소리 저장 안 함), 안 되면 자동으로 🌐 기본(크롬) 방식. 안내사항 카드의 칩으로 전환. 받아쓴 문장은 한 문단으로 이어 붙음.
- AI 받아쓰기 체감 속도: 말하는 동안 `🎙 듣는 중 ●●●`, 조각은 말이 0.45초 멈추면 최소 2.2초부터 바로 전송(최대 7초), 받은 문장은 단어씩 타이핑하듯 빠르게 표시.
- 기본(크롬) 인식도 체감 속도 개선: 말하는 즉시 `🎙 듣는 중`, 인식 중인 글자가 흐리게 문단 끝에 바로 이어져 보이다가 확정되면 진해짐.
- **조회/종례 끝 = 자동 저장 + AI 요약**: `✅ 조회 끝`/`종례 끝`을 누르면 받아쓰기를 멈추고 안내사항을 저장한 뒤 Workers AI(Llama 3.3 70B)가 학생용 글머리 3~6줄로 요약(말씀에 있는 내용만, 날짜·과목·제출물 유지). 요약은 같은 기록(`jongrye:<날짜>`)의 `summary`에 저장되어 학생 홈 카드(요약 먼저, 원문은 펼침)와 칠판 오늘 화면 상단 배너에 표시. 요약 실패 시 원문만 유지하고 화면은 그대로 넘어감. 안내사항을 다시 고치면 요약은 지워짐.
- **일정 탭 > 지난 조회/종례**: 목록·캘린더·주간 시간표 옆에 `지난 조회/종례` 보기 추가. 최근 45일 조회/종례 기록을 날짜별로(요약 먼저, 원문 펼침). 더보기의 지난 기록 창도 같은 목록 사용.
- 요약 보강: AI 요약이 실패해도 규칙 기반 요약(`ruleSummary`)을 저장해 기록이 항상 요약으로 남음. 지난 조회/종례 목록은 KV를 병렬 조회(청소·이탈 기록도)하고, 저장해 둔 목록을 먼저 보여 준 뒤 갱신(stale-while-revalidate). 요약이 없는 옛 기록은 화면에서 간이 요약으로 표시.
- **미니게임(2인 대전)**: 전자칠판 하단 `🎮 미니게임`·학생 앱 더보기. 한 화면을 좌우로 나눠 서로 마주 보고(왼쪽 1P 시점, 오른쪽은 180° 회전해 2P 시점 → 각자 아래가 나, 위가 상대) 총알은 자동 발사, 손가락을 끌어 자유 이동(키보드 1P WASD / 2P 방향키). 체력 15, 아이템 ❤회복·⚡연사·✴3갈래, 승패·누적 승수·다시하기. 소리는 기본 꺼짐. `public/game.js`.
- 칠판 헤더(`n교시 수업 중` 왼쪽)에 `🎓 수능까지 N초` 초 단위만 표시(2028학년도 수능, 2027-11-18 목 08:10 KST 기준). 입실 시각은 평가원 시행계획(2027년 3월 공고) 확정 후 `kiosk.js`의 `SUNEUNG_AT`에서 수정.
- 미니게임 나가기: 상단 `✕ 나가기`(게임 중엔 3초 안에 한 번 더 눌러야 나감), 끝난 뒤 화면에 큰 `🔁 다시 하기`/`🚪 게임 나가기` 버튼.
- **원 그리기 게임**: 게임 고르기 화면(`🎮 미니게임`)에서 `⭕ 원 그리기`. 한 번에 원을 그리면 가운데 점을 중심으로 고정한 원과 비교해 정확도(%)를 채점(반지름 흔들림·시작/끝 이어짐·한 바퀴 여부·덧그리기 감점), 잘 그린 곳은 초록→벗어난 곳은 빨강으로 표시, 기기별 최고 기록 저장. 2인 대전과 함께 `public/game.js`.
- **오늘 일정에 맞춘 일과 시간(칠판)**: 오늘 일정의 안내(`info`)에 `N교시 · HH:MM~HH:MM`·`종례 · HH:MM 이후` 줄이 있으면 그 시간으로 교시 표시·수업 중/쉬는 시간·자습 남은 시간·청소(15분)→종례(5분) 자동 전환을 맞추고, 그날 없는 교시는 숨김(⚡ 특별 일과 표시). 없으면 기존 주간 시간표(+50분).
- **조회 끝 → 종례로**: `✅ 조회 끝`을 누르면 그 조회 내용이 요약과 함께 기록(`hist`)으로 옮겨지고 안내사항 칸은 비워져, 다시 조회/종례 탭을 열면 종례 화면이 열림. 화면 위에 `🌅 오늘 조회 요약` 접을 수 있는 카드(요약, 원문 보기)가 남음. 종례 끝도 같은 방식. 학생 홈·일정 탭 > 지난 조회/종례에는 조회·종례가 따로 표시.
- **내신 2학기 선택과목 자동 반영**: 학교 기준 선택과목 명단(`official`)이 있으면 내신 2-2 표에도 5과목을 학점 3으로 자동 추가(융합선택은 내신 제외 기본), 이미 저장된 표라도 빠진 과목만 추가하고 입력한 등급은 유지, 등급 없는 다른 선택과목 행은 정리.
- **특별 일과(안내의 시간표)를 칠판·학생 앱·푸시에 모두 반영**: 일정 안내(`info`)의 `N교시 · HH:MM~HH:MM`, `점심 · HH:MM~HH:MM`, `청소 · HH:MM~HH:MM`, `종례 · HH:MM 이후` 줄을 읽어 오늘 일과(교시 시각·점심·청소)·현재 교시 표시·청소→종례 자동 전환을 맞춤. 학생 홈의 요일 시간표와 알림장·푸시의 일과 줄도 같은 시각 사용. 11/20(금) 단축 일과(조정안) 반영.
- **시험 카운트다운**: 칠판 헤더에 `📝 기말고사 D-17 · N초`(첫 시험 시작 시각까지; 일정에 `중간고사`/`기말고사`가 있으면 가장 가까운 것). **새 버전 자동 새로고침**: 빌드 해시를 `/api/version`·`window.BUILD`로 비교 — 칠판은 1분마다 확인해 게임·받아쓰기·의견 보드 중이 아닐 때 자동 새로고침, 학생 앱은 앱으로 돌아올 때 바로 새로고침(입력 중이면 `🔄 새 버전` 알림 줄).
- **미니게임 2인 대전 = 결투(Duel) 초안**: 각자 자기 진영에서만 이동(가운데 노란 선은 못 넘음), 총알은 자동이 아니라 화면 오른쪽 아래 `🔥` 버튼을 눌러 발사(키보드 1P `F` / 2P `Enter`). 탄창 5발·빈 탄창은 0.85초마다 1발씩 재장전(⚡ 아이템은 재장전 가속), 총알은 느려서 피할 수 있음, 체력 8, ❤ 회복/✴ 3갈래 아이템은 양쪽 진영에 랜덤 생성.
- **자습 화면 자리표**: 자습 화면 가운데에 자리표(자리 바꾸기와 같은 배치)를 띄워 교실 이탈 등록된 사람은 점선·흐림 + `🚪 사유 · N분`으로 표시, 위에 `재석 29 / 31명 · 이탈 N명`. 자리를 누르면 이탈 등록(이름 미리 선택), 이탈한 자리를 누르면 돌아옴.
- **새로고침해도 화면 유지**: 칠판은 마지막으로 본 화면(오늘/청소/조회·종례/자습/자리 …)을 12시간 동안 기억해 새로고침·자동 업데이트 뒤에도 그대로 열고, 학생 앱은 주소의 탭 외에 마지막 탭(12시간)과 일정 탭의 보기(목록/캘린더/주간/지난 조회·종례)·기말고사 탭의 보기를 기억함. 로그아웃하면 지움.
